# IR Camera — Spec

| Field | Value |
| --- | --- |
| Sensor | OV2311 monochrome, global shutter |
| Resolution / fps | 2 MP @ 50 fps |
| Interface | USB 2.0 / UVC (V4L2 + MJPG on the Pi) |
| Lens | Low-distortion M12, ~83° H FOV |
| Filter | 780 nm long-pass — blocks visible <780 nm, transmits NIR above |
| Focus | Tuned to ~25 cm sharp, infinity acceptable |
